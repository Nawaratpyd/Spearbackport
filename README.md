# Spear Backport (NeoForge 1.21.1)

หอก (Spear) จาก Minecraft เวอร์ชันใหม่ พอร์ตมาลง 1.21.1
โค้ดและเท็กซ์เจอร์ทั้งหมดเขียน/วาดใหม่เอง ไม่ได้คัดลอกจากเกมหรือจากม็อดอื่น

## สิ่งที่มี
- หอก 7 แบบ: ไม้, หิน, ทองแดง, เหล็ก, ทองคำ, เพชร, เนเธอไรต์ (อยู่ในแท็บ Combat ของ Creative)
- **แทง (jab):** คลิกซ้ายตีปกติ
- **ชาร์จ:** กดค้างคลิกขวา (รอสักครู่) แล้ววิ่งเข้าใส่ศัตรู ยิ่งวิ่งเข้าหาเร็ว ดาเมจยิ่งสูง (บนหลังม้าได้ดาเมจแรงมาก)
- สูตรคราฟต์: วัสดุ 1 ชิ้น + แท่งไม้ 2 อัน วางเรียงเฉียง
  ```
  . . X
  . / .
  / . .
  ```
- เนเธอไรต์: อัปเกรดจากหอกเพชรที่โต๊ะ Smithing (เหมือนอุปกรณ์เนเธอไรต์ทั่วไป)
- ใส่เอนชานต์ได้: Sharpness, Fire Aspect, Knockback, Unbreaking, Mending, Vanishing ฯลฯ

## ยังไม่มี
- เอนชานต์ Lunge
- ท่าถือหอกแบบเกมจริง (ตอนนี้ใช้ท่าถือแบบ Trident)
- ค่าดาเมจ/ความเร็ว/ความทนทานเป็นค่าประมาณ ปรับแต่งได้

## ปรับค่า
เปิดไฟล์ `src/main/java/com/example/spearbackport/SpearItem.java` ส่วน `Tuning` ด้านบน:
`WINDUP_TICKS` (เวลารอก่อนชาร์จพร้อม), `MIN_SPEED` (ความเร็วต่ำสุดที่จะโดน),
`SPEED_DAMAGE_FACTOR` (ดาเมจเพิ่มต่อความเร็ว), `MAX_SPEED_BONUS`, `REACH`

## วิธี build
อัปโหลดโปรเจกต์ขึ้น GitHub แล้วให้แท็บ Actions build ให้ (ดูไฟล์ `.github/workflows/build.yml`)
หรือติดตั้ง JDK 21 + Gradle แล้วรัน `gradle build` ไฟล์ม็อดอยู่ที่ `build/libs/`

ก่อน build ให้ตรวจเลขเวอร์ชันใน `build.gradle` ให้ตรงกับที่ใช้ได้ผลกับม็อด Distance Leveling
